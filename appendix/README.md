## 快速索引：已知限制

写生产脚本前建议先看[已知限制](internals.md#已知限制)，重点包括：

- 失败时退出码为 0；
- 对象遍历顺序不稳定；
- 调用栈信息不完整；
- 循环 import 会卡死；
- 没有 `throw`；
- 并发共享状态需要显式加锁；
- 少数标准库 API 存在缺陷（`file.append`、`count()`、`db.tables()` 等）。

这些问题都有对应的规避写法，详见正文。
